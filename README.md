# PDF to Interactive HTML skill

A reusable Codex skill for transforming evidence-rich PDFs into accurate, mobile-friendly interactive HTML explainers, stories, quizzes, and educational games.

## Install

Copy the `pdf-to-interactive-html` folder into your Codex skills directory, then start a new task and ask Codex to transform a PDF into an interactive HTML experience.

## Included guidance

- Evidence extraction and printed-page traceability
- Explicit evidence, inference, recommendation, and data-gap labels
- Responsive, accessible, self-contained HTML delivery
- Educational game loops and child-friendly adaptations
- Privacy-safe behavioural-data recommendations
- Local artifact, download, and optional public-hosting boundaries

The skill contains general workflow instructions only. It does not include the Woolworths annual report, customer information, or other source documents.
